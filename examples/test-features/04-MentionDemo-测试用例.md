# MentionDemo 测试用例

## 测试目标

验证 MentionDemo（Mention — @ 候选人 + 职位）的所有功能路径，包括 Mention 扩展的触发字符激活、异步搜索（fetchItems）与竞态保护、弹窗列表渲染、键盘导航（上下箭头/Enter/Escape）、候选人/职位分类显示、mention 标签插入到编辑器、标签点击、JSON 内容提取、以及与 Submit 扩展的交互（弹窗激活时 Enter 不提交）。

## 前置条件

- 页面已加载，当前 tab 切换到「候选人 + 职位」
- 编辑器处于受控模式（value + onChange）
- Mock 数据包含：候选人 8 人（kind="2"）+ 职位 6 个（kind="1"）
