# ChatDemo 测试用例

## 测试目标

验证 ChatDemo（聊天场景）的所有功能路径，这是最综合的 Demo，集成了 Mention + Submit + 受控模式的完整聊天流程。包括：Mention 标签选择、Enter 提交消息、提交后清空编辑器、消息列表渲染、addSourceAttr 源数据序列化、以及各扩展之间的协作。

## 前置条件

- 页面已加载，当前 tab 切换到「聊天场景」（默认 tab）
- 编辑器处于受控模式
- Mock 数据包含候选人 8 人 + 职位 6 个
