# BasicDemo 测试用例

## 测试目标

验证 BasicDemo（基础用法 — 纯文本 + Enter 提交）的所有功能路径，包括非受控模式的 Editor 组件、Submit 扩展的提交/拦截逻辑、以及 UI 反馈展示。

## 前置条件

- 页面已加载，当前 tab 切换到「基础用法」
- 编辑器处于非受控模式（无 value prop）

---

## TC-BASIC-001：编辑器初始化渲染

| 项目     | 内容                                          |
| -------- | --------------------------------------------- |
| 输入     | 页面加载，切换到「基础用法」tab               |
| 步骤     | 1. 观察编辑器区域是否渲染                     |
| 预期结果 | 1. 编辑器显示 placeholder 文本「输入内容后按 Enter 提交...」 |
|          | 2. 标题「1. 基础用法 — 纯文本 + Enter 提交」可见 |
|          | 3. 说明文字「非受控模式，按 Enter 提交，Shift+Enter 换行。空内容不触发提交。」可见 |
|          | 4. 「已提交」列表不存在（messages 为空）      |

## TC-BASIC-002：正常输入文本

| 项目     | 内容                          |
| -------- | ----------------------------- |
| 输入     | 点击编辑器，输入 "Hello World" |
| 步骤     | 1. 点击编辑器获得焦点         |
|          | 2. 依次输入 "Hello World"     |
|          | 3. 观察 placeholder 消失和文本显示 |
|          | 4. 打开浏览器控制台查看 onChange 输出 |
| 预期结果 | 1. 焦点获取成功，placeholder 消失 |
|          | 2. 编辑器内显示 "Hello World" |
|          | 3. 控制台输出 `[Basic] onChange:` 及对应 HTML（`<p>Hello World</p>`） |
|          | 4. 「已提交」列表仍不存在     |

## TC-BASIC-003：Enter 键提交 — 编辑器有内容

| 项目     | 内容                                    |
| -------- | --------------------------------------- |
| 输入     | 编辑器中已输入 "测试消息"               |
| 步骤     | 1. 输入 "测试消息"                      |
|          | 2. 按 Enter 键                          |
|          | 3. 观察「已提交」列表                   |
| 预期结果 | 1. 「已提交」区域出现                   |
|          | 2. 列表中新增一条消息，格式为「消息 1: HH:MM:SS」 |
|          | 3. 控制台无报错                         |

## TC-BASIC-004：Enter 键提交 — 连续多次提交

| 项目     | 内容                                |
| -------- | ----------------------------------- |
| 输入     | 编辑器中有内容                      |
| 步骤     | 1. 输入 "第一条"，按 Enter 提交     |
|          | 2. 输入 "第二条"，按 Enter 提交     |
|          | 3. 输入 "第三条"，按 Enter 提交     |
| 预期结果 | 1. 「已提交」列表显示 3 条消息      |
|          | 2. 消息编号依次为「消息 1」「消息 2」「消息 3」 |

## TC-BASIC-005：空内容提交被拦截（shouldSubmit 返回 false）

| 项目     | 内容                                    |
| -------- | --------------------------------------- |
| 输入     | 编辑器为空（无任何文字输入）            |
| 步骤     | 1. 点击编辑器获得焦点                   |
|          | 2. 不输入任何内容，直接按 Enter 键      |
|          | 3. 观察「已提交」列表                   |
| 预期结果 | 1. 不触发 onSubmit 回调                 |
|          | 2. 「已提交」列表仍不存在               |
|          | 3. 编辑器状态不变                       |

## TC-BASIC-006：Shift+Enter 换行

| 项目     | 内容                              |
| -------- | --------------------------------- |
| 输入     | 编辑器中有光标                    |
| 步骤     | 1. 输入 "第一行"                  |
|          | 2. 按 Shift+Enter                 |
|          | 3. 输入 "第二行"                  |
| 预期结果 | 1. 第一行显示 "第一行"            |
|          | 2. Shift+Enter 后光标移至新行     |
|          | 3. 第二行显示 "第二行"            |
|          | 4. 不触发 onSubmit                |

## TC-BASIC-007：onChange 回调 — 非受控模式

| 项目     | 内容                                    |
| -------- | --------------------------------------- |
| 输入     | 编辑器处于非受控模式                    |
| 步骤     | 1. 输入任意文本 "abc"                   |
|          | 2. 查看控制台输出                       |
| 预期结果 | 1. 每次输入变化时，控制台输出 `[Basic] onChange: <p>a</p>` → `<p>ab</p>` → `<p>abc</p>` |
|          | 2. onChange 的 html 参数为当前编辑器 HTML 内容 |

## TC-BASIC-008：Enter 提交后编辑器状态

| 项目     | 内容                                    |
| -------- | --------------------------------------- |
| 输入     | 编辑器中已输入 "提交测试"              |
| 步骤     | 1. 输入 "提交测试"                      |
|          | 2. 按 Enter 提交                        |
|          | 3. 观察编辑器内容                       |
| 预期结果 | 1. onSubmit 触发，「已提交」列表新增一条 |
|          | 2. 编辑器内文本 "提交测试" 仍然存在（BasicDemo 的 onSubmit 不清空编辑器） |

## 覆盖路径总结

| 路径                                        | 测试用例              |
| ------------------------------------------- | --------------------- |
| 非受控模式初始化 + placeholder 展示         | TC-BASIC-001          |
| 文本输入 + onChange 触发                    | TC-BASIC-002, 007     |
| Enter → shouldSubmit=true → onSubmit        | TC-BASIC-003, 004, 008|
| Enter → shouldSubmit=false（editor.isEmpty）| TC-BASIC-005          |
| Shift+Enter → 换行（不触发 onSubmit）       | TC-BASIC-006          |
| messages 状态累加 + UI 列表渲染             | TC-BASIC-003, 004     |
