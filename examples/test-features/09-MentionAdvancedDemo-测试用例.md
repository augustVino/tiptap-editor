# MentionAdvancedDemo 测试用例

## 测试目标

验证 MentionAdvancedDemo（Mention 高级配置 — 自定义列表 + 字段映射 + 源数据序列化）的所有功能路径，包括 fieldNames 字段映射（userId/name → id/label）、listComponent 自定义列表（UserList 组件渲染 avatar/department/role）、addSourceAttr 选择性序列化（仅 email + department）、onTagClick 回调、debounceMs 防抖搜索、emptyText 自定义空文本、tippyOptions 弹窗自定义、getMentionSourceFromJSON / getAllMentionSourcesFromJSON 源数据提取、以及受控模式下的 HTML/JSON 实时同步。

## 前置条件

- 页面已加载，当前 tab 切换到「Mention 高级配置」
- 编辑器处于受控模式（value + onChange）
- Mock 数据包含：6 位同事，字段名为 userId/name/email/department/avatar/role（非 id/label）
