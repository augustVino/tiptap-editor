# FileHandlerDemo 测试用例

## 测试目标

验证 FileHandlerDemo（文件处理 — 图片粘贴/拖放）的所有功能路径，包括 MIME 类型过滤（image/* 通配符匹配）、粘贴和拖放两种文件输入方式、被拒绝文件的回调处理、以及 UI 展示（已接收文件列表、被拒绝文件列表）。

## 前置条件

- 页面已加载，当前 tab 切换到「文件处理」
- 编辑器处于非受控模式
- 准备测试文件：一张 PNG 图片（如 `test.png`）、一张 JPG 图片（如 `photo.jpg`）、一个非图片文件（如 `document.pdf` 或 `test.txt`）

---

## TC-FILE-001：文件处理初始化渲染

| 项目     | 内容                                            |
| -------- | ----------------------------------------------- |
| 输入     | 页面加载，切换到「文件处理」tab                 |
| 步骤     | 1. 观察编辑器区域                               |
| 预期结果 | 1. 编辑器显示 placeholder「粘贴或拖放图片到此处...」 |
|          | 2. 标题「3. 文件处理 — 图片粘贴/拖放」可见      |
|          | 3. 说明文字「只允许图片文件 (image/*)。非图片文件会触发 onRejected 回调。」可见 |
|          | 4. 「已接收文件」列表不存在                     |
|          | 5. 「被拒绝文件」列表不存在                     |

## TC-FILE-002：粘贴单个图片文件

| 项目     | 内容                                      |
| -------- | ----------------------------------------- |
| 输入     | 一个 PNG 图片文件（`test.png`）           |
| 步骤     | 1. 复制一张 PNG 图片到剪贴板              |
|          | 2. 在编辑器中执行粘贴操作（Ctrl+V / Cmd+V）|
|          | 3. 观察「已接收文件」列表                  |
|          | 4. 观察控制台输出                          |
| 预期结果 | 1. onPaste 回调被触发                     |
|          | 2. 「已接收文件」列表显示 `test.png (image/png)` |
|          | 3. 控制台输出 `[FileHandler] onPaste: 1 files, html: true/false` |
