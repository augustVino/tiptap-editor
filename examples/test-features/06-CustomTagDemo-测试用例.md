# CustomTagDemo 测试用例

## 测试目标

验证 CustomTagDemo（自定义标签渲染 + 多触发字符）的所有功能路径，包括：自定义 tagComponent（CandidateTag / PositionTag）的渲染、两种不同触发字符（`@` 候选人 / `#` 职位）的独立 Mention 扩展、自定义标签点击交互、标签内类型标识显示、以及多 Mention 扩展共存。

## 前置条件

- 页面已加载，当前 tab 切换到「自定义标签」
- 编辑器处于受控模式
- 配置了两个独立的 Mention 扩展：
  - `@` 触发 → `customCandidate` → `fetchCandidates` → `CandidateTag`
  - `#` 触发 → `customPosition` → `fetchPositions` → `PositionTag`
