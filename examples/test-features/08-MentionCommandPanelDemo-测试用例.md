# MentionCommandPanelDemo 测试用例

## 测试目标

验证 MentionCommandPanelDemo（命令面板 — Slash Command 模式）的所有功能路径，包括：insertToEditor:false 模式下 mention 节点不插入编辑器、trigger 字符 `/` 触发命令弹窗、自定义 listComponent（CommandList）渲染带图标和描述的命令列表、关键词搜索过滤、无匹配时 emptyText 显示、键盘上下箭头导航、Enter/鼠标选择执行 onSelect 回调、Escape 关闭弹窗、各命令的具体操作（插入时间、清空编辑器、插入模板、仅日志命令）、onSelect context 参数验证、日志面板格式与条数限制、以及 `/` 与 `@` 触发字符互不干扰。

## 前置条件

- 页面已加载，当前 tab 切换到「命令面板 — Slash Command 模式」
- 编辑器处于非受控模式（无 value/onChange）
- Mock 数据包含 6 条命令：插入时间、清空编辑器、插入模板、切换全屏、加粗文字、保存草稿
