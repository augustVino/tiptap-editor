# ControlledDemo 测试用例

## 测试目标

验证 ControlledDemo（受控模式 — 双向绑定 + ref 操作）的所有功能路径，包括受控 Editor 的 value/onChange 同步、EditorRef 的所有方法（focus/blur/clear/setContent/insertContent/getHTML/getText/getJSON/isEmpty）、editable 只读模式切换、以及实时内容预览。

## 前置条件

- 页面已加载，当前 tab 切换到「受控模式」

---

## TC-CTRL-001：受控模式初始化渲染

| 项目     | 内容                                          |
| -------- | --------------------------------------------- |
| 输入     | 页面加载，切换到「受控模式」tab               |
| 步骤     | 1. 观察编辑器区域                             |
|          | 2. 观察操作按钮栏                             |
|          | 3. 观察内容预览区                             |
| 预期结果 | 1. 编辑器显示 placeholder「受控模式输入...」  |
|          | 2. 标题「2. 受控模式 — 双向绑定 + ref 操作」可见 |
|          | 3. 5 个操作按钮可见：「聚焦」「清空」「设置内容」「插入内容」「只读模式」 |
|          | 4. 两个 `<details>` 折叠面板可见              |
|          | 5. 「实时内容 (HTML)」面板默认折叠            |

## TC-CTRL-002：受控模式输入 — value/onChange 双向绑定

| 项目     | 内容                              |
| -------- | --------------------------------- |
| 输入     | 编辑器中输入 "Hello"             |
| 步骤     | 1. 点击编辑器获得焦点             |
|          | 2. 输入 "Hello"                   |
|          | 3. 展开「实时内容 (HTML)」面板    |
| 预期结果 | 1. 编辑器内显示 "Hello"           |
|          | 2. content state 更新为 `<p>Hello</p>` |
|          | 3. 「实时内容 (HTML)」面板显示 `<p>Hello</p>` |

## TC-CTRL-003：ref 操作 — 聚焦（focus）

| 项目     | 内容                                        |
| -------- | ------------------------------------------- |
| 输入     | 编辑器未聚焦                                |
| 步骤     | 1. 点击编辑器外部区域使编辑器失焦           |
|          | 2. 点击「聚焦」按钮                         |
| 预期结果 | 1. 编辑器重新获得焦点                       |
|          | 2. 光标出现在编辑器内                       |

## TC-CTRL-004：ref 操作 — 清空（clear）

| -------- | --------------------------------- |

| 步骤     | 1. 输入 "要清除的内容"            |

|          | 3. 「实时内容 (HTML)」面板内容为空 |
|          | 4. placeholder 重新显示           |

## TC-CTRL-005：ref 操作 — 设置内容（setContent）

| 项目     | 内容                                      |

|          | 2. content state 更新为 `<p>通过 ref 设置的内容</p>` |

## TC-CTRL-006：ref 操作 — 插入内容（insertContent）

## TC-CTRL-007：ref 操作 — 只读模式切换

| 项目     | 内容                                      |
| -------- | ----------------------------------------- |
| 输入     | 编辑器处于可编辑状态                      |
| 步骤     | 1. 点击「只读模式」按钮                   |
|          | 2. 尝试在编辑器中输入文本                 |
|          | 3. 观察按钮文字变化                       |
|          | 4. 再次点击「恢复编辑」按钮               |
|          | 5. 再次尝试输入                           |
| 预期结果 | 1. 切换为只读后，编辑器无法输入           |
|          | 2. 按钮文字变为「恢复编辑」               |
|          | 3. 点击「恢复编辑」后，编辑器恢复可输入  |
|          | 4. 按钮文字变回「只读模式」               |

## TC-CTRL-011：ref 读取 — isEmpty()

| 项目     | 内容                                  |
| -------- | ------------------------------------- |
| 输入     | 编辑器状态分别为空和非空              |
| 步骤     | 1. 不输入任何内容，点击「isEmpty()」   |
|          | 2. 输入 "内容"                        |
|          | 3. 再次点击「isEmpty()」              |
| 预期结果 | 1. 第一次 alert 显示 `true`           |
|          | 2. 第二次 alert 显示 `false`          |

## TC-CTRL-012：受控模式 — value prop 外部更新

| 项目     | 内容                                              |
| -------- | ------------------------------------------------- |
| 输入     | content state 通过非编辑器途径变化                |
| 步骤     | 1. 在编辑器中输入 "原始内容"                      |
|          | 2. 点击「设置内容」按钮（通过 ref.setContent 修改）|
|          | 3. 观察 content state 是否同步                    |
| 预期结果 | 1. setContent 触发编辑器内容变更                  |
|          | 2. 编辑器 onChange 回调更新 content state         |
|          | 3. 「实时内容 (HTML)」面板内容与编辑器显示一致    |

## TC-CTRL-013：折叠面板交互

| 项目     | 内容                                      |
| -------- | ----------------------------------------- |
| 输入     | 两个 `<details>` 面板处于折叠状态        |
| 步骤     | 1. 点击「实时内容 (HTML)」summary        |
|          | 2. 点击「通过 ref 获取的内容」summary    |
|          | 3. 再次点击「实时内容 (HTML)」summary    |
| 预期结果 | 1. 第一次点击：面板展开，显示 pre 内容   |
|          | 2. 第二次点击：面板展开，显示 4 个按钮   |
|          | 3. 第三次点击：第一个面板折叠             |
